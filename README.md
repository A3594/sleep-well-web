# 숙면웹

마이크 소리 크기 패턴으로 밤중 소음, 코골이 추정, 깸 가능성, 잠 깊이 추정을 기록하는 설치형 웹앱입니다.

## 주요 기능

- 원음 저장 없이 소리 지표와 이벤트만 로컬 저장
- 15초 조용한 기준 자동 보정
- 방해 소리, 코골이 추정, 깸 가능성 기록
- 소리 안정도 기반 잠 깊이 추정
- 1명/2명 수면 인원 설정
- 2명 모드에서 폰 위치 기준으로 나/상대/구분 어려움 추정
- 같이 자는 모드로 반복 코골이 소리의 점수 반영 완화
- 시작 후 어두운 수면 화면 자동 전환
- 시작음악과 기상음악 재생, 각각 최대 30분 설정
- 기본음, 휴대폰 오디오 파일, 직접 음악 링크 선택 및 저장
- 정해둔 기상 시간에 알림 및 기상음악 재생
- 화면 유지 옵션
- PWA 홈 화면 설치 지원

## 실행 방법

```powershell
python -m http.server 4175 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:4175`로 접속합니다.

마이크, 알림, PWA 설치는 HTTPS 또는 localhost에서 가장 안정적으로 동작합니다.

## 주의

소리만으로 실제 수면 단계나 원인을 정확히 판정할 수는 없습니다. 이 앱은 참고용 기록 도구입니다.
마이크 하나로 두 사람의 소리를 완전히 분리할 수는 없으므로 2명 모드의 사람별 구분은 추정값입니다.
